1.0.46: Added HTTPS support for new RainBird firmware controllers (LNK WiFi module with HTTPS-only communication).
        Protocol is auto-detected on first request: HTTP is tried first; on connection failure HTTPS is used and cached permanently.
        Self-signed certificate accepted (rejectUnauthorized: false). Switch is logged to console.
1.0.47: Performance improvements:
        - HTTP/HTTPS keep-alive persistent connections (reuse TCP, one socket per controller).
        - Inter-request queue delay reduced from 100ms to 50ms.
        - checkCommandSupport() result cached for lifetime of instance (eliminates redundant probe on every rainbird-state call).
        - Agents properly destroyed on Node-RED flow reload (config node close handler).
        - rainbird-active queries controller state at 0.5s and 3s after start/stop zone command.
